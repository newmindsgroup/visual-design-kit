## Turn the knowledge into AI-usable work

For each selected guide, attach the communication problem, relevant audience and medium, required source/baseline IDs, choices and rationale, preserve/change rules, production settings and evidence to the existing design-work record. The stage handoff must identify the exact artifact/version the next skill consumes. Reuse existing source, reference, token and manifest owners; do not add a second brief or parallel approval system.

Each technique needs an explanation of when it helps, when it harms, a worked example, a rejected alternative, an output specification and an actual check. A list of styles or adjectives is insufficient instruction for Codex or Claude Code. Keep essential conditions in the entry skill and detailed examples in linked references, selected only when relevant.

## Suggested sequence

1. Start priority 10's critique criteria with priority 1: freeze the brief, invariants and observable checks, and name the project design owner as adjudicator of taste/direction. A model may recommend; do not invent user approval. Author the image art-direction and composition guide under the existing foundations/identity routes. Create a small same-brief example before growing the reference collection.
2. Adapt that same approved example across formats, then add typography/localization stress cases. This reuses one baseline and makes differences reviewable.
3. Add a retail display storyboard and later verify the actual environment. In parallel only if separately justified, deepen icons, information design or print for the first project that needs them.
4. Package selected mature guides and run a fresh-project loading check. Packaging remains required but should not make shallow guidance look complete.

Advanced 3D, shaders, elaborate scroll experiences, generative media subscriptions and more inspiration-site integrations remain conditional. Add one when a brief demonstrates its communication benefit and the production route can be checked. None is a prerequisite for excellent work.
