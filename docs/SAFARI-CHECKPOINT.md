# Safari accessibility checkpoint
Version-Timestamp: 2026-10-14 15:14:00 AST

Native Safari on the authoring Mac: dialog opens, exposes its title and description in the accessibility tree, initially focuses Close, closes with Escape and returns focus to the trigger. Option+Tab and Option+Shift+Tab wrap between the dialog controls. Plain Tab under the current Safari keyboard preference moved focus outside the panel; this remains a finding to investigate. Drawer-specific native Safari checks are incomplete. This record does not claim Safari acceptance.

VoiceOver was briefly enabled, then switched off at the user request; off state confirmed in System Settings. No speech announcements were captured or validated. Do not enable VoiceOver again without a new explicit request. VoiceOver acceptance remains incomplete. Chrome automated accessibility results do not substitute for a screen-reader test.
