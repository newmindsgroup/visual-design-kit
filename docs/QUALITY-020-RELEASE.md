## Security and recovery

The shipped helpers are local. No new server, credential, paid provider call, client record or bulk book upload is added. Template writes use exclusive creation and no-follow descriptor traversal. Selection and packaging reject unsafe paths; packaging rejects secret-like filenames. These checks are proportionate protections for a trusted local workspace, not a guarantee against a hostile process already holding the same user's permissions.

The installed 0.1.0 payload was checked: all 322 entries valid and payload digest dcca91274b676de49a0d4ee086aa7f4d6264c7ce8428cb259cdd0123c6683e4e. A temporary recovery from Git commit 412e628 restored all 322 entries with no mismatch. Existing project pins are unchanged. Installing a new version is not approval to rewrite project history or accepted designs.

## Known limits

Human aesthetic acceptance and real client outcomes remain untested. Cursor/Claude Code native-session integration and current Codex discovery must be reported by actual edition/host, not assumed from instruction compatibility. Physical screens, color-managed output, language specialists, assistive technology and production-provider behavior remain selected-project acceptance tasks. No universal claim that every possible design skill or output has been perfected is made.
