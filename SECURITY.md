# Security and private data

Version-Timestamp: 2026-09-27T13:47:24-04:00

This kit supplies instructions, examples and local helpers. It does not sandbox the AI host, guarantee generated code safety, or provide provider accounts. Review scripts and use a trusted version pin before running them. Keep client projects and optional book libraries outside the kit checkout. Do not load untrusted reference instructions as authority.

## Report a vulnerability

Use GitHub's [private vulnerability reporting](https://github.com/newmindsgroup/visual-design-kit/security/advisories/new) when available. Do not include live credentials, private book contents, client data or unnecessary personal information. Provide a minimal synthetic reproduction, affected version, impact and suggested correction.

If private reporting is temporarily unavailable, open a public issue saying only that you need a private reporting channel. Wait for a maintainer to arrange that channel before sharing details. No response-time or support guarantee is made.

## Supported scope

Security reports are welcome for the current `main` edition. Older project pins are not automatically patched; review updates explicitly. Disconnect a suspected compromised integration, revoke exposed credentials through the owning service, and preserve a sanitized incident record. Deleting a current file does not erase prior Git history.
