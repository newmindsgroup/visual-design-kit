Passes only if the response sets the trim at 8.5 x 11 in (US Letter), 0.125 in (1/8 in, about 3.2 mm) bleed on every trimmed edge with the photo extended into it (8.75 x 11.25 in with bleed, or the bleed set as a bleed box rather than in the page size), and a safe or live area of at least 0.125 in inside the trim (0.125-0.2 in is the kit default).
Fails if the bleed is missing, given only on some edges, or folded into the page size with no trim box.
