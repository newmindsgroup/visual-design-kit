Passes only if the prompt:
- Opens with a stack line suited to Lovable (React, Vite, TypeScript, Tailwind CSS, shadcn/ui, with an animation library such as motion or framer-motion) and puts the palette as CSS variables (HSL variables in `index.css` is Lovable's convention; another explicit variable block is acceptable).

- Uses numbered sections, exact copy for headline, sub, nav and CTA, and numbers rather than adjectives (sizes with clamp() or per breakpoint, durations and easing).
- Ends with explicit "Do not" constraints (for example no extra sections, no placeholder or stock images, no purple gradients, no emoji icons, no invented testimonials).

Fails if the prompt describes the look in adjectives ("warm, elegant") without values, or drops the accent rule.
