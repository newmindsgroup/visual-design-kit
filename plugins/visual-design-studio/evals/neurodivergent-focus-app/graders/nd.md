Passes only if the response:
- Avoids pressure patterns and says so: no countdown timers by default, no streak loss, no urgent red badges, no guilt copy; time shown as an optional visible aid (for example elapsed or remaining time the user chooses), not a threat.
- Reduces sensory load: no autoplay, sound and haptics off or optional, an in-app reduce-motion setting beyond the OS setting, calm color with no flashing.
- Supports executive function: one current task emphasized, breaking tasks into steps, visible progress that does not depend on memory, undo, confirmation before losing work.
- Keeps things predictable: same controls in the same places, no surprise modals or redirects, literal labels and copy.
- Lets people tune the interface: density, theme, font choice, quiet mode or notification batching under the user's control.
- Names at least one sourced standard or font choice: W3C COGA, WCAG 2.2 (for example 2.2.2, 3.2.6, 3.3.7), the British Dyslexia Association style guide, or Atkinson Hyperlegible/Lexend with dyslexia fonts only as an option.
Fails if the design centers gamified streaks, leaderboards or urgency timers.
