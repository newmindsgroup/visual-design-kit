Passes only if the response requires 1-color black and 1-color white-on-black versions in which no part relies on the gradient or color to separate, says the gradient must be replaced by a flat 1-color drawing for the stamp, and mentions a reversed master (strokes reduced about 2-5% for light-on-dark) or a reversed test.
Fails if it proposes the stamp or one-color use with the gradient converted to a halftone or simply dropped without redrawing.
