Passes only if the value ($3) direction gives concrete values that differ from the luxury direction: a named bold or condensed sans (for example Barlow Condensed, Anton, Archivo, Oswald); saturated hex values with high shelf contrast; a large readable benefit and size callout; a simple low-cost structure and print (PP or HDPE tub, few colors, no foils); and legibility from shelf distance.
Fails if the typeface is described only by category ("a bold sans"), the palette has no hex values, or both lines share the same type and palette with only a finish change.
