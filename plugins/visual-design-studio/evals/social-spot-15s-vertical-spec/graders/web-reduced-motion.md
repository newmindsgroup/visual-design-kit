Passes only if the website hero version is specified as a muted, `playsinline` loop with no audio track and a poster frame, a small file (about 1-3 Mbps, H.264 MP4 plus WebM), a visible pause control because autoplaying motion over 5 seconds needs pause, stop or hide (WCAG 2.2.2), and a `prefers-reduced-motion: reduce` behavior (poster image or paused), with no more than three flashes per second (WCAG 2.3.1) mentioned for the kinetic type.
Fails if the hero autoplays with no pause control or no reduced-motion behavior.
