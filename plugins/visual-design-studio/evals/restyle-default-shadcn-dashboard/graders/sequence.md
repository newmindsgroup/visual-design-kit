Passes only if the plan is reference-first and ordered:
- Starts with evidence: collect real product references (several screens and at least one complete flow, for example from Mobbin, Refero or comparable shipped dashboards) and explain which pattern to borrow and why before redesigning. Adjective-only briefs ("modern, clean, premium") are named as the problem.
- States the job and the user of the overview screen (for example a clinic manager checking today's appointments, overdue invoices or no-shows at the start of the day) and lets that set what is big.
- Components second (keep shadcn's behavior, restyle it), motion last, after layout and visual system are stable.
- The Claude Code brief names the component libraries, constrains the system up front (one accent and its job, type scale, spacing unit, light/dark), includes an avoid list, iterates in small specific passes, and suggests persisting the rules in AGENTS.md (or equivalent project instructions).

Fails if the plan starts by restyling or adding effects without gathering references, or if the brief is a list of adjectives.
