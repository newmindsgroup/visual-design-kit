## Scope

Client-agnostic methods for new websites, redesigns, individual pages and precise revisions. Reuse research, personas, brand, type, color, content, motion and UI inventories. A selected skill is not an installed plugin or a working integration. Keep actual project decisions and approvals in the existing [design record](templates/design-work.md), adding the relevant [website sections](templates/website-work.md).

## Sequence and handoffs

1. Discovery, existing audit where relevant and prioritized requirements establish scope.
2. Content strategy, sitemap and page architecture establish what each page communicates and how it connects.
3. Art direction, responsive compositions and design-system assembly turn approved content into page designs.
4. Frontend and selected CMS/platform implementation realize the design. Define integrations and privacy before collecting data.
5. Fidelity, accessibility, performance, SEO and browser checks produce evidence and repairs.
6. Authorized launch follows approved versions and recovery planning; maintenance uses observed results.

Choose conditional commerce, accounts, localization, directory, editorial, booking or rich storytelling only when relevant. A one-page brochure needs no invented login, sitemap hierarchy or transaction flow. A narrow copy edit reuses valid inputs and performs fit checks without reopening strategy. An existing approved design system should be extended rather than replaced.
