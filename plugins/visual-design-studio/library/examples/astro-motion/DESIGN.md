# Motion Atlas design contract

Version-Timestamp: 2026-10-14 11:06:44 AST

## Purpose
A visual reference and coded component library for website designers. Show a working effect, the reason to use it, its fallback and source. This is a code demonstration, not a no-code animation authoring tool.
## Ground and color
Graphite #171a1d, paper #f6f7f5, muted #62696e, line #d8ddda, soft #e9ede9. Signature amber #B08838 used for tiny active marks and strokes, about 2% of the interface. Experimental stage fixtures may use sage #97aca3 and slate #657f95, clearly separate from client brand tokens.
## Typography
System sans for interface and large editorial title. System monospace for specimen metadata. No external fonts. Fluid display scale, readable 16px body and bounded line lengths.
## Layout
Wide quiet header, numbered effect list with generous rows, two-column specimen/detail page. Mobile stacks all content, controls wrap. One clear Preview action per effect.
## Surface
No shadows. Hairline borders, ground shifts, restrained rounded controls. No fake logos or client claims.
## Motion
Static initial content, explicit replay. Everyday and experimental tiers are visible. Operating-system reduced motion always wins. Pause preserves meaning. Native focus ring and pointer remain.
## Interactions
Preview pages allow replay, pause, reduced preview and return to library. Effect-specific controls are native buttons or documented accessible patterns. No hidden initial content.
## Responsive
Desktop at 1440px, phone at 390px, narrow at 320px. Scroll specimens use labeled bounded scrollers, never trap the page.
## Evidence
Headless Chrome desktop/touch/mobile and screenshots are required. Safari, Firefox, real mobile hardware, field performance and aesthetic approval remain separate.
