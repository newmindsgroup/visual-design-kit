Using the template

The design-director skill copies _template/stylescape.html once per candidate direction, fills the token block and every data-slot, replaces the key visual, renders at 1440 and 390 px, and compares the pages side by side before scoring.

Open the empty template

Viewing locally

From plugins/visual-design-studio/library run python3 -m http.server and open /examples/stylescapes/. Pages make no network requests.

Rules every page follows

  • Token-contract CSS variable names
  • Self-hosted OFL fonts with license files
  • WCAG 2.2 AA, computed ratios, visible focus
  • Reduced-motion fallbacks; 390 and 1440 px layouts
All brands are fictional. Artwork is CSS and inline SVG. Fonts are SIL Open Font License 1.1, see fonts/<family>/OFL.txt. Data: brands.json · README
