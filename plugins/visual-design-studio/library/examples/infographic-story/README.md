A bounded fictional example, not a client-approved template or proof of comprehension. Two directions explain the same 12/8/4 synthetic category counts: category comparison and share of total. Use the [web example](index.html), PDF presentation (generate and inspect a new PDF from the supplied web source; no prebuilt PDF is included), [source data](data.json) and [generator](build.py). Run the generator from the repository root.

Choose the comparison layout when ranking categories matters; choose the part-to-whole layout when the main message is the share of all items. Explicit scale labels prevent the two types of chart from implying the same denominator. Mobile reflows the two panels; it does not shrink a fixed poster.

Scoped evidence: an independent Opus review returned on milestone vd-infostory-20260910. Its valid findings were addressed with an image role/name, explicit scales, thinner internal separators, and a PDF data appendix. Four-width measurements checked chart ratios after correcting a border-related distortion. Nine-width heading inspection found no single-word final lines in the measured version. Keyboard and overflow checks passed; desktop/mobile screenshots and PDF pages were inspected. Detailed intermediate evidence remains private. These are bounded checks, not universal accessibility or typography certification.

The PDF is generated separately through browser print with details expanded and tagging enabled. A tagged PDF alone does not establish reading order or screen-reader usability. No native editable master, real audience study or physical print proof has been completed. The source is editable HTML/CSS and Python. Fonts use Arial/system fallback; do not adopt this pair for unrelated brands without selection.

Do not reuse the synthetic counts as real demand, cost, time or outcome evidence. This example adds no new capability and does not change the existing production or approval requirements.
