## Compare before looking at the key

For each brand open `specimen.html?brand=form` or `brand=tidal`. Compare the same brief at the same viewport against `&variant=generic` and `&variant=wrong`. Send reviewers the brief and neutral screenshot IDs first, without model/provider/candidate-class labels. Ask for a recommendation, visible reasons, failures, tradeoff and next repair. Reveal the key after that assessment. This is a bounded review, not a blind audience study.

<details><summary>Control answer key</summary>

- FORM generic: keeps facts and the image, but generic sans type, rounded image frame and stock button treatment reduce the intended quiet material character. Correctness does not establish distinctiveness.
- FORM wrong: polished treatment adds an unsupported clinical sleep claim. Reject regardless of attractive presentation.
- TIDAL generic: keeps the community message and photograph, but the generic interface styling weakens the sporting editorial direction.
- TIDAL wrong: an exclusive luxury message and sepia treatment conflict with an open, active community. Brand fit is not a popularity vote between attractive palettes.

</details>

## Precise revision and recovery

The `revised` variant changes only the headline: FORM becomes “An everyday object, quietly considered.” TIDAL becomes “A shared morning. A fresh perspective.” Source photo, wordmark, other copy and tokens must match the same brand's candidate. Record browser inspection and invariant checks separately. These are exercise baselines, not invented client approval.

The [continuity record](CONTINUITY.md) identifies exact baseline/current/rejected states and stale-asset, palette and unauthorized-label fault cases. A resumed worker reads that record and the actual files before selecting a candidate. JSON equality alone cannot prove pixels or render fidelity.

## Typography and motion

[Typography controls](typography.html) include a known orphan, actual clipped text, and a valid short action label. The first two must be detected and the last must not be rejected. Candidate compositions use exact locally served open-license fonts. Browser tests inspect narrow, intermediate and wide widths, blocked-font fallback and user text-spacing overrides. These checks are scoped evidence, not a blanket accessibility certification.

[Motion study](motion.html) uses a twelve-second editable sequence. [Timeline](timeline.json) declares phases, reading holds and invariants; [motion source](motion.js) is the implementation. The web motion is deliberately graphic composition around a stable photograph, not generated live-action video. Static final state and text transcript accompany it. Export, full timing observation, seam comparison and representative frame review are recorded separately. No physical display has been tested.

## Reference decision RD-TYPE-01

Original method: choose type for audience character and reading role; fit measure, size and spacing together; verify rendered words after fonts load. Use typography as part of the visual idea, not an arbitrary font swap.

Source consulted locally: Alina Wheeler and Rob Meyerson, *Designing Brand Identity: A Comprehensive Guide*, source ID `c1f4d06250ac0cea`, PDF page 177, printed page 159, “Typeface family basics” and “Type terminology and parameters.” Both the indexed passage and original page layout were inspected. The page discusses family character, legibility, range and typesetting variables. It does not prescribe our palettes, selected fonts, particular line lengths, browser tests or a universal ban on every single-word line. Those are scoped design decisions and user requirements, not claims attributed to the book. The full book and page image remain outside the shared kit.

Public execution guidance: [W3C text spacing](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html) and [W3C reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html). User spacing must not lose content; a narrow viewport test is recorded separately from actual browser zoom. Font provenance and SIL Open Font Licenses are included under assets. Book search is optional, local and read-only through the packaged reference helper. This one passage inspection is not a claim to have fully reviewed every book.

Headline-only revision scope includes fitting its type size within the existing text area, using the same brand family, weight and color. Other regions and content remain fixed. First renders of the longer replacement headings produced orphans; local headline sizing was adjusted and rechecked. This is a documented authorized exercise delta, not a hidden global typography change.
