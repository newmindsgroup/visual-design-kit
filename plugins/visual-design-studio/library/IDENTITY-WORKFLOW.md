## Sequence and ownership

Strategy/name precedes original logo concepts; selected concepts feed refinement and variants. Evaluation checks the resulting artifacts; guidelines and delivery consume accepted decisions. Refresh is an alternative entry using an existing identity, not a compulsory new-brand stage. A locked existing logo can go directly to evaluation or delivery without concept generation. A typography-only revision must not trigger renaming. Dependencies are accepted input contracts, not commands to repeat all upstream work.

Design Taste can critique a website, display, infographic or presentation directly using its own brief; the identity record is only required for identity work. It provides critique and refinement, not strategy approval. Shared [content](draft-skills/design-content-writing/SKILL.md) owns voice/slogans/taglines, [typography](draft-skills/design-typography/SKILL.md) owns type, [color](draft-skills/design-color-system/SKILL.md) owns palettes, [motion](draft-skills/design-motion-effects/SKILL.md) owns timed identity and [visual language](templates/visual-language-system.md) owns supporting families. Do not duplicate their rules.

## Logo presentation

Show brief and concept idea, clean standalone mark, comparable alternatives, rationale, realistic applications, small-size/monochrome proof, tradeoffs, recommendation and focused decision questions. Clearly label proposed mockups and unapproved variants. Reuse [creative direction](CREATIVE-DIRECTION.md); presentation polish never substitutes for vector or reproduction checks.

## Verification boundary

Use [handoff record](templates/identity-handoff.md). Authoring and structural tests do not prove decision quality or final artwork. Planned behavioral cases: fixed existing name and locked mark, new brand with unresolved name, precise kerning correction, and non-identity website critique. Actual tool rendering, audience evidence, specialist clearance and physical reproduction stay separate.
