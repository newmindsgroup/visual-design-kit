# Applied design methods

Version-Timestamp: 2026-09-27 14:20:29 AST

These original method cards teach decisions that can be made with the kit and the project's authorized inputs. They require no private reference collection. They are authored guidance, not a claim that a design has been produced, tested, or accepted. Every miniature is fictional teaching material. No example is a default style, real audience finding, or production baseline.

Start with the selected capability, then read one card matching the unresolved decision. Open a second only when its decision is needed next. Do not load the entire library. Keep the project's brief, authority, evidence and allowed changes in control. A method can explain how to work with missing information; it cannot supply missing product facts, permissions or user research.

## What is new, what is reused

| Card | Added reasoning | Reused authority |
| --- | --- | --- |
| Research | Prioritize uncertainty by the decision it could change; compare conflicting evidence without averaging it | Existing research evidence classes, scope and handoff |
| Direction | Translate an evidence-backed attribute into a visible operation, compare equal-content concepts, then generalize a family | Existing direction comparison, identity ownership and family rules |
| Typography | Diagnose line-fit failure and repair the composition in an explicit order | Existing font discovery, file/license/axis/fallback fields and rendered checks |
| Color | Separate recognition, functional meaning and actual foreground/background behavior | Existing token ownership, contrast criteria and pair records |
| UX/content | Move from task uncertainty to testable states and truthful message/action pairs | Existing audience selection, research and UX/content contracts |
| Infographics | Choose encoding from the reader's comparison and preserve denominator/uncertainty through adaptation | Existing data element IDs, calculations, alternatives and export requirements |
| Screen/motion | Choose message beats, image medium and choreography as one communication decision | Existing storyboard, product truth, motion fallback and target verification |
| Critique/delivery | Turn a visible defect into a bounded repair and propagate only affected rechecks | Existing change boundary, approval, manifest and delivery process |

These methods are original synthesis of practical decision problems and the kit's existing public-facing contracts. They do not reproduce or summarize private books. Optional deeper references can expand a selected question when available and authorized; their absence does not prevent these methods from being used. Current legal, accessibility, platform and production requirements still need their applicable authoritative source and actual checks. Cards deliberately avoid inventing universal ratios, timings, palette meanings or acceptance scores.

For each application, put the card path/version, decision it informed and chosen/rejected options in the existing work record’s **Decisions and work** section. Put the check method in **Criterion basis** and actual evidence or remaining limits in **Checks and limits**. These are method inputs, not book-source records. A clean record proves organization; it does not prove craft, usability, legal rights or release readiness.
