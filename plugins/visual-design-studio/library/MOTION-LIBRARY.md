Version-Timestamp: 2026-10-14 11:13:07 AST

Select `web-astro` for Astro implementation and `web-motion-library` for original components/effect recipes. The existing `motion` capability still owns purpose and choreography. The reference is a coded component collection, not a global website theme.

[Open the source playground](examples/astro-motion/README.md), [stack research](draft-skills/design-web-astro/references/research.md), [motion entry](draft-skills/design-web-motion-library/SKILL.md), [lifecycle](draft-skills/design-web-motion-library/references/lifecycle.md), [verification](draft-skills/design-web-motion-library/references/verification.md).

Coverage: feedback, disclosure, tabs, keyed-list movement, carousel, reveals/staggers, kinetic type, SVG, progress, parallax, sticky scrub, pointer tilt/magnetic/spotlight, masks, ambient canvas, lazy WebGL and page transitions. Advanced recipes cover native timelines/shared elements, pinning/horizontal scroll/video, Lenis, SplitText, shape morph/path, layout FLIP, springs/inertia, shaders/WebGPU, Lottie, gradients, audio-reactive scenes and custom navigation covers.

Keep technique status separate from tier. An experimental technique can be implemented while an everyday recipe is researched only. Scope client adoption to actual project tests and approved evidence; no universal production, performance or accessibility claim follows from this release.
