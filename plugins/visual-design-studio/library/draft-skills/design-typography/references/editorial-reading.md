# Editorial reading composition

Status: authored method, not a newly executed reading study. Use for reports, articles, guides and substantive sales documents. A hero section or short ad does not automatically need this treatment.

Start from the accepted copy outline, reading task, delivery medium and brand/type decisions. In the existing [work record](../../../templates/design-work.md), identify the entry point, sustained explanation, supporting evidence, navigation and conclusion. Decide which text is a title, standfirst, paragraph, caption, quotation or utility label. Do not manufacture quotes, bylines, statistics or chapter counts to populate a template.

Build a representative opening and a dense internal section before extending the whole document. Use actual approved copy where available; otherwise label a realistic fixture. Compare hierarchy through scale, weight, spacing and measure. Change only what improves scanning or reading for this content. A restrained report and an expressive magazine can both be appropriate. Tight tracking, light display weights, serif type and asymmetrical spacing are choices to test, not universal requirements.

Use a pull quote only when it has a clear reading purpose and a traceable source. Preserve the complete meaning and attribution. If it duplicates body content decoratively, define how the accessible reading order avoids unnecessary repetition; if it adds meaning, keep it available. Keep captions close to their figures and reserve adequate room for citations, bylines and qualifications.

For web, test narrow screens, enlargement, text spacing, long headings, links and fallback fonts. For paginated output, inspect widows/orphans, heading separation, table splits, running information and actual page references. Measure at the intended reading size; a zoomed-out spread is not evidence of readable body copy. For multilingual content, verify shaping, glyph coverage and punctuation with actual text. Do not impose Latin tracking, line-height or italic conventions on another script, and do not ban a genuine supported type style solely by language name.

Return the content-role map, proposed reading rhythm, affected token references, representative specimens and actual checks with remaining holds. Keep approved identity decisions unchanged unless a specific revision is authorized. Numeric sizes, line lengths and rhythm ratios are project choices justified by the specimen, not copied defaults.
