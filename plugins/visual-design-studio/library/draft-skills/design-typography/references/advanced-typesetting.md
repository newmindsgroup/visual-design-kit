# Microtypography and multilingual composition

Version-Timestamp: 2026-09-11T19:32:14-04:00

Check punctuation, quotation marks, apostrophes, dashes appropriate to the project voice, fractions, units, superscripts, currencies and nonbreaking constructs using real content. Do not mechanically alter code, identifiers or approved names. Test hyphenation dictionaries per language and ensure justified columns do not produce rivers or excessive gaps. Hanging punctuation and ligatures are optional font/renderer features; verify actual output.

For bilingual/mixed-script layouts compare perceived scale, baseline relationships, reading direction and line rhythm without forcing different scripts into identical metrics. Never apply Latin tracking rules to connected scripts by default. Verify shaping, combining marks, numeral conventions and line-break prohibitions with appropriate language review. Use authentic licensed sample text; do not fabricate a language validation result.

For variable fonts inspect the exact file axes/ranges, optical-size behavior and named instances. Test chosen values in each target renderer. Record static fallback and missing-axis behavior. The existing type decision owns font/version/axes; do not create a second authority.

For each web/PDF/native output inspect actual font identity, missing glyphs, substitution, text selection, line endings and embedded/outlined intent. Capture repeated specimens at narrow/large sizes and with font failure and text enlargement. Automated wrap findings are review candidates, not permission to shrink text or rewrite approved copy.
