# Free font discovery without repeating a default

Version-Timestamp: 2026-09-08 20:15:10 AST

Discovery status: public sources checked 2026-09-08; no font files downloaded, installed, rendered or approved here. Exact release licenses, coverage, axes and recipient rights must be inspected at selection time. These are examples of different directions, not a mandatory menu or cross-client pairings.

Search beyond these examples through [Google's font repository](https://github.com/google/fonts), original foundry repositories and [Fontshare](https://www.fontshare.com/). Google hosts font files under several license directories; inspect each selected license. Fontshare includes a proprietary free-font license, so do not assume an open-source license or permission to redistribute. The [Fontshare license page](https://www.fontshare.com/licenses/itf-ffl) was only partially readable in this research and must be read fully before adopting those files. Never equate a specimen service subscription with font-file redistribution rights.

[Elliot Jay Stocks's author checklist](https://github.com/elliotjaystocks/choosing-type-checklist) is a useful independent reference for selection; these instructions are original, not a copied checklist. [SIL's OFL guidance](https://openfontlicense.org/ofl-faq/) distinguishes using fonts in artwork from redistributing or modifying the font software. [Web font performance guidance](https://web.dev/articles/font-best-practices) explains why fallback metrics and loading behavior need actual inspection.

For discovery, record source, exact candidate/version, intended role, reason it could fit, unresolved license/coverage issue and next test. Carry only accepted candidates forward. Expand the shortlist when none meets requirements, not simply to maximize the number of fonts considered.
