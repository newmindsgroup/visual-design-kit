Choose fonts using the existing typography decision record and exact licenses. Then test the actual content, not just an alphabet. Compare display, body, control labels, numbers and dense data separately. Character may help a heading while harming a small control.

Set a plausible body size and line length for the medium; adjust leading against actual x-height, density and language. Compare loose versus cramped tracking at intended size. Large compressed headings often need explicit word-space attention. Avoid letterspacing connected scripts without script-specific guidance. Optical-size axes are font-specific; confirm the font exposes the axis before setting it. Width axes change line fit and texture; do not distort outlines with arbitrary horizontal scaling as a substitute.

Check real weights, italics, punctuation, accents, currency, fractions and ambiguous glyphs. Use proportional numerals for ordinary prose when suitable and tabular numerals for comparable data columns when supported. Font feature settings are hypotheses until rendered in the selected file. Build an actual fallback comparison with blocked requests; record changed wrapping and layout shift. Font files and license notices travel with the allowed output route, never from an unverified specimen screenshot.

## Brand-name and symbol pairing specimens

Use when brand typography or adjacent lettering lacks personality, authority, readability or optical integration. Preserve the original typography as a control and record whether replacement, pairing or only typesetting is authorized. Do not rename, recapitalize or alter a locked mark to suit a font. For typesetting-only authority, skip font discovery and replacement shortlists: compare the unchanged control and corrected view using the same family, with icon paths unchanged.

Turn the brief into visible selection criteria: intended personality, audience/category context, category-appropriate authority when relevant, reading conditions, language coverage, width constraints and compatibility with the symbol's curve/stem/terminal rhythm. Authority is a contextual judgment, not a font category; neither serif nor geometric sans is automatically more professional.

Build a bounded shortlist of meaningfully different candidates and the original baseline. Use existing approved files first, then official foundry/distributor discovery sources as needed. Record source, exact family/style/file/version or available metadata, required weights/axes and license status for actual desktop/artwork/web/embedding/redistribution uses. Keep discovered, locally available, rendered and rights-approved statuses separate. A listed family name, subscription or machine installation does not establish required rights. Use existing verified files; discovery grants no purchase or installation authority. Apply the typography entrypoint installation boundary.

Render the complete approved brand name (including descriptors, case, diacritics and punctuation) in each candidate using the actual selected font file and real style. If the original family is unknown, use the preserved artwork as the control and label it unresolved rather than inventing a match. The artwork control is exempt from live-text/font-file requirements: record its visible text and any difference from the approved full name; unmatched content is contextual baseline evidence, not an equal-content comparison. Preserve it unchanged. Do not upload client artwork for font identification without project-specific data authorization. Record requested versus rendered native family/style and any substitution; unresolved availability or license keeps production adoption pending. Provisional evaluation requires files whose use for that evaluation is permitted; label the remaining production-rights hold. Keep discovered-only or unavailable candidates in the record, excluded from rendered comparison sheets; label production adoption pending. A foundry preview may be included separately as attributed discovery evidence, never as a rendered full-name specimen. Do not substitute a visually similar fallback and call it the candidate.

Create both a wordmark-only sheet and symbol-plus-name lockup sheet. Compare an equal nominal-size view and a matched optical-size view, recording nominal size and measured visible cap/x-height or other relevant visible reference. Choose the reference for the actual case/script; keep aspect ratios and log intentional width-axis settings. Do not normalize away width, weight or terminal personality differences. Keep the same text, background, symbol master and intended use across comparisons.

Inspect personality/authority fit, width/proportion, stroke contrast, apertures/counters, ambiguous letters, letter and word spacing, difficult pairs, rhythm, baseline and actual small-size reading. Adjust kerning on the candidate as allowed; compare unadjusted and corrected views, preserving the exact approved name and live-text source for new text candidates; the preserved artwork control remains separately identified. Check whether icon and type share or intentionally contrast visual weight, curve rhythm, apparent height and spacing. A strong font alone cannot rescue an unreadable monogram, and a strong icon does not excuse weak adjacent lettering.

Present alternatives with a specific benefit, tradeoff, observed failure and recommendation tied to the brief. If none meets the criteria, refine the shortlist rather than selecting the familiar default. Keep design judgment separate from user approval, audience reading evidence and license/native/export acceptance. Carry exact specimens, rendering receipts and comparison measurements in the existing typography decision record.
