# Video editing for displays

Version-Timestamp: 2026-09-11T19:51:13-04:00

## Objective and inputs

Produce video editing for displays within the user's screen-content scope. Read the [screen workflow](../../SCREEN-CONTENT-SKILLS.md) and reuse approved upstream files, brief, source versions and constraints. The catalog dependency `screen-assets` identifies required information, not a mandatory rerun. Missing inputs are explicit assumptions or scoped holds.

## Method

Select footage for the intended message, then reframe each shot for the target canvas. Preserve important subjects and approved text. Prefer deliberate layouts over excessive crops. Record speed changes and color treatments; keep source timecodes.

## Output

Editable edit, shot/source list and target-format preview. Carry source version, candidate status, editable file location, dependencies, limitations and next owner in the [handoff](../design-stage-handoff/SKILL.md). Choose an available tool suited to the artifact; a skill does not establish authentication, paid allowance or native editing capability.

## Acceptance

Inspect subject clipping, source softness, frame cadence and unlicensed audio; remove audio only as required by delivery. Record actual evidence and failures. Never label an unexecuted check passed. Maintain the approved baseline until the candidate is accepted.
