# Website and SEO copy

Version-Timestamp: 2026-09-08 15:36:02 AST

Use the accepted audience, offer, page inventory, search evidence and intended action. Establish page purpose, primary reader question, section order, proof needs and CTA destination before drafting. Coordinate with sitemap/content model rather than create pages solely for keywords.

Selected outputs include home/about/service/product/pricing/landing copy, headings, navigation, FAQs, titles/descriptions, internal-link text, media descriptions and editorial briefs. Record each page/section ID and content owner. Match search intent and actual offer; label unresearched keyword ideas as hypotheses. Never invent search volume, customer questions or ranking evidence.

Write complete useful answers, clear benefits and supported proof; use natural terminology and meaningful link labels. For image alternatives describe the image's purpose in context, not keyword stuffing. Distinguish proposed metadata from deployed tags and schema from supported visible facts. Technical indexing, redirects, structured data and migration execution need the appropriate implementation owner.

Check reading flow, factual consistency, CTA behavior, duplicate intent, heading meaning, mobile wrapping and localization. Browser checks remain pending until performed. No universal word count, fixed snippet length or ranking guarantee. Handoff: versioned page/section copy, metadata proposals and internal destinations to layout/CMS/implementation.
