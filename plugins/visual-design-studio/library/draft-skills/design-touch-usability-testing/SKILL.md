# Touchscreen usability testing

Version-Timestamp: 2026-09-11T20:08:06-04:00

## Inputs and scope

Read the [advanced workflow](../../DISPLAY-ADVANCED-SKILLS.md). Reuse accepted `touch-device-validation` inputs, source versions, objective and constraints. Dependencies express information needs, not mandatory repeated work. Scope is screen content and interaction, not fixture design. Unknown facts remain unknown.

## Method

Define representative tasks and recruit relevant users with consent. Observe without coaching first. Record completion, confusion, accidental taps, recovery and assistance. Separate observed issues from hypotheses and proposed fixes. Use physical tests for reach and glare.

## Deliverable and handoff

Task protocol, observation sheet, findings and prioritized repairs. Include exact files actually created, candidate status, assumptions, failed checks and next owner through the [handoff](../design-stage-handoff/SKILL.md). Proposed paths are not produced files. No installed tool, publication authority or provider access is implied by this skill.

## Acceptance

Retest changed behavior and preserve failures; synthetic walkthroughs do not count as user studies. Record observations separately from expected behavior. Missing runtime evidence remains pending; do not label plans or descriptions tested. Keep prior approved versions recoverable.
