# Design Taste

Version-Timestamp: 2026-09-11T19:25:03-04:00

Status: authored project-local instruction. No installation or production acceptance implied.

## Inputs and routing

Start with the actual artifact, brief, audience and approved constraints. For identity work, use the [identity workflow](../../IDENTITY-WORKFLOW.md) and its handoff record. For other media, use the existing project work record and relevant specialist; do not create an identity project merely to critique a website or infographic. Reuse accepted reference decisions.

## Method

Use the actual brief, audience, medium, brand constraints and visual artifact. If only prose is available, label feedback conceptual. Read relevant foundations, typography, color, motion or identity methods progressively. Do not impose one font, minimalism, gradients or a fashionable style on unrelated projects.

Assess hierarchy, spacing, rhythm, proportion, optical balance, text measure, image treatment, material coherence, originality and fit. Separate factual/functional defects from preference. Explain what to change, why and how it serves the brief. For text, inspect actual line wrapping and orphaned words at target sizes; never fix one breakpoint by causing overflow or unreadably small type elsewhere.

Use references to explain relationships, not copy distinctive assets. Offer a small prioritized set of concrete improvements, then compare equal-content before/after artifacts. Preserve approved locks and avoid rewriting unrelated work. Explain subjective disagreement honestly. An attractive mockup or automated score cannot prove audience effectiveness; avoid claiming best-in-class without comparative evidence. Record accepted lessons through existing reviewed skill improvement, not automatic universal rules.

## Output and acceptance

Annotated critique, prioritized actionable changes, rationale, alternative tradeoffs and actual before/after evidence when executed.

Carry file versions, approval scope and unresolved checks through [stage handoff](../design-stage-handoff/SKILL.md).
