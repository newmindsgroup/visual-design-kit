# Display image finishing

Version-Timestamp: 2026-09-11T20:08:06-04:00

## Inputs and scope

Read the [advanced workflow](../../DISPLAY-ADVANCED-SKILLS.md). Reuse accepted `display-production` inputs, source versions, objective and constraints. Dependencies express information needs, not mandatory repeated work. Scope is screen content and interaction, not fixture design. Unknown facts remain unknown.

## Method

Inspect final encoded output, not only the working file. Check gradients, banding, sharpening halos, compression blocks and thin details. Use actual target profile and playback constraints. Compare a high-quality reference with delivery encoding before adjusting treatment.

## Deliverable and handoff

Finishing log, reference render and delivery render. Include exact files actually created, candidate status, assumptions, failed checks and next owner through the [handoff](../design-stage-handoff/SKILL.md). Proposed paths are not produced files. No installed tool, publication authority or provider access is implied by this skill.

## Acceptance

Inspect native size and player output; distinguish capture artifacts from display defects. Record observations separately from expected behavior. Missing runtime evidence remains pending; do not label plans or descriptions tested. Keep prior approved versions recoverable.

## Media quality extension

Version-Timestamp: 2026-09-11T21:08:20-04:00

Assemble accepted imagery with editable type, logos, prices and disclaimers in the appropriate native editor. Preserve masks, source links, fonts and effect parameters rather than flattening the only master. Check clean edges, color treatment, resampling, banding and sharpening at final resolution. Inspect typography after every format adaptation: repair orphan words with width, line composition or size changes without shrinking below readable limits. Export to the supplied player specification; desktop inspection cannot certify hardware. See [media workflow](../../MEDIA-QUALITY-WORKFLOW.md).
