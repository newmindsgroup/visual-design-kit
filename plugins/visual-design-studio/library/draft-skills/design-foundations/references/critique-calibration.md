Freeze the communication brief, content, intended audience/use and invariants before comparing revisions. Define observable criteria such as missing qualifiers, clipping, contrast, illegible type, incorrect values and misleading interaction separately from taste criteria such as character or balance. State which items are standards, project requirements or heuristics.

Compare versions of the same artifact using identical text and target conditions. Name the defect, its consequence, proposed minimal correction, unchanged properties and actual check. Do not change copy, image subject and layout together and then claim the layout alone caused improvement. Different art directions can be compared as choices but are not a controlled before/after test.

Inspect renders before scoring. Record pass/revise/not-tested per criterion; do not average a failed factual/access requirement into a favorable aesthetic score. Human design ownership remains explicit. The AI can recommend a direction and carry agreed invariants forward, but cannot invent user approval, audience preference or conversion evidence.

Preserve weak/revised sources with clear labels. Negative examples are teaching evidence only, excluded from normal reference lookup and never used as project defaults. A first-party model review is independent critique, not an actual user study. Carry unresolved disagreements, rationale and next evidence into the handoff. Stop when scoped criteria are met rather than endlessly generating variants.

## Automated findings and house style

Treat a pattern detector as a lead with its source snippet and known limits. Separate measured requirement failures from aesthetic preferences and verify each finding in context. A named color, gradient, symmetrical layout or font genre is not inherently defective; approved brand intent governs unless a real requirement fails. Maintain explicit exceptions with rationale rather than letting a generic style ban override the brand. Reopen missing evidence instead of treating an absence of lint findings as proof of quality.
