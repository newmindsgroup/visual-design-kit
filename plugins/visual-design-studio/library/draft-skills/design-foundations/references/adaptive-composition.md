Define the reading sequence before the grid: entry point, explanation, evidence, action and qualification. Classify content as invariant, safely shortenable with meaning preserved, supporting detail or optional decoration. Do not shorten regulated qualifiers or factual conditions without authority.

Choose a structure for the content: editorial columns for extended reading, modular grid for repeated comparable units, asymmetric composition for one strong focal point, typographic poster for a short message, or image-led layout for a subject that carries meaning. Repeated cards are useful for repeated units, not automatically for every section. Optical alignment can correct a mathematically centered but visually imbalanced form; record the reason rather than inventing a universal ratio.

For each format record content order, text scale, margins/safe regions, crop/focal point, image replacement, density and interaction differences. A slide can depend on a presenter only when speaker context is part of its use. Passive displays must carry the message without a click. Recompose at content failure points rather than selecting breakpoints solely by device names. Use responsive image sizes for resolution selection and art-directed crops when composition changes; preserve the image alternative's meaning across sources.

Check long/short content, loading/fallback, user text spacing, narrow widths, zoom and each fixed export. Compare facts and stable message IDs across variants. Produce a format matrix and actual artifacts linked from the work record. Keep one owner of shared content; the retail guide evaluates context around the display variant rather than creating a second composition.
