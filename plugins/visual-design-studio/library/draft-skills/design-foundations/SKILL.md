## Apply the vocabulary to a decision

| Element | Decision to make |
| --- | --- |
| Line and edge | Separation, direction, drawing character and stroke consistency |
| Shape and form | Silhouette, grouping and depth; distinguish 2D marks from actual geometry |
| Color and value | Contrast, emphasis, meaning and background relationships |
| Texture and material | Tactility or atmosphere without harming legibility or truth |
| Space and scale | Density, margins, negative space, proportion and viewing distance |
| Typography and imagery | Voice, reading hierarchy and how the subject is represented |
| Time and movement | Sequence, feedback, pacing and orientation when motion is needed |

| Principle | Practical critique |
| --- | --- |
| Hierarchy and emphasis | One useful entry point; emphasis matches importance |
| Balance and proportion | Intentional symmetric/asymmetric weight; relationships survive resizing |
| Contrast and variety | Enough distinction to communicate, without competing focal points |
| Alignment and grid | Consistent relationships, with optical correction where geometry misleads |
| Repetition and rhythm | Reuse creates recognition; deliberate variation avoids monotony |
| Unity and coherence | Type, imagery, color and shape belong to one direction |
| Proximity and common region | Related content is visibly grouped; unrelated items are not merged |
| Similarity and continuity | Repeated treatment implies the same role; paths remain understandable |
| Figure-ground and closure | Important shapes/text separate clearly; implied forms remain legible |
| Common fate | Shared movement implies a relationship; do not imply false grouping |

These are design heuristics, not guarantees about every viewer. Do not force every principle into every artifact. Golden ratios, a fixed spacing scale or a vendor's minimalism are options, not universal laws.

## Method and output

Identify the communication problem before selecting style. If direction is open, compare two or three distinct concepts through the existing reference-decision record, holding core content constant. Name the composition, type character, color roles, asset approach and motion purpose, with evidence for fit and reasons to reject alternatives. If identity is fixed, retain it and explore within its permitted range.

Use typography, color or motion capabilities only where the task needs them. Include semantic structure, information density, crop behavior and reading order in composition decisions. Review realistic content, not placeholder copy. Record the selected direction and next consumer in design-work.md; link tokens and selected inventory items without cloning them.

Apply the craft review to actual artifacts when available. Without a render, report only specification review. Acceptance requires an inspectable direction, preserved invariants, explained choices, linked evidence and named untested conditions. Production/delivery retain ownership of native files and final checks.
