# Attention and message sequencing

Version-Timestamp: 2026-09-11T20:08:06-04:00

## Inputs and scope

Read the [advanced workflow](../../DISPLAY-ADVANCED-SKILLS.md). Reuse accepted `display-content` inputs, source versions, objective and constraints. Dependencies express information needs, not mandatory repeated work. Scope is screen content and interaction, not fixture design. Unknown facts remain unknown.

## Method

Distinguish passing, approaching and dwelling viewers. Prioritize recognizable product and one main takeaway; sequence secondary detail only when dwell supports it. Design mid-loop entry and silent comprehension. Treat dwell estimates as hypotheses until observed.

## Deliverable and handoff

Attention brief and message/beat map. Include exact files actually created, candidate status, assumptions, failed checks and next owner through the [handoff](../design-stage-handoff/SKILL.md). Proposed paths are not produced files. No installed tool, publication authority or provider access is implied by this skill.

## Acceptance

Inspect several entry times and actual viewing distance; do not infer attention from playback counts. Record observations separately from expected behavior. Missing runtime evidence remains pending; do not label plans or descriptions tested. Keep prior approved versions recoverable.

## Screen-zone hierarchy

Version-Timestamp: 2026-09-11T21:22:42-04:00

Produce a content-zone map with screen ID, normalized bounds, message priority, focal asset, reading order and dwell assumption. Give one message primary emphasis within the viewer's simultaneous field of view; secondary zones must support it rather than compete through equally strong movement, brightness or scale. Record which zones may move together and which stay quiet. For multiple screens, judge the combined view as well as each export. Test mid-loop arrival and passing versus dwelling contexts. A small thumbnail or brief exposure exercise is a diagnostic, not proof of real shopper attention. Return the map with the storyboard and record any unverified viewing-distance assumptions.

Use the [display production detail checklist](../../templates/display-production-details.md) and preserve actual test evidence.
