# Lettering and optical correction

Version-Timestamp: 2026-09-11T19:32:14-04:00

Start with exact approved text, language, concept and a preserved master. Build repeated stems, bowls and terminals into a coherent system, then inspect exceptions rather than enforce identical geometry. Compare counterforms and pair spacing by apparent area; test troublesome diagonal/round/straight combinations. Ligatures must improve the intended reading and retain recognizability. Do not use arbitrary horizontal scaling to imitate a width design. Keep custom artwork distinct from modifications to licensed font software.

Inspect at real small size and enlarged. Compare geometric and optical alignment side by side, light/dark and monochrome. Overshoot, weight and spacing corrections are candidates, not fixed percentages. Record changed points/letters and test legibility before accepting. Preserve separate size-specific approved variants. The synthetic circle/triangle study in the lab illustrates comparison only, not a prescribed correction.

Deliver annotated vector before/after, exact text proof, native master and a correction log. If the tool cannot produce editable paths, label a raster concept and route actual production separately.
