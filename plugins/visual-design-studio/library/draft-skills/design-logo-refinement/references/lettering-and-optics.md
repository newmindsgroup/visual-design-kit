Start with exact approved text, language, concept and a preserved master. Compare counterforms and pair spacing by apparent area; test troublesome diagonal/round/straight combinations. Ligatures must improve the intended reading and retain recognizability. ## Controlled contour and integration study

Use when an authorized refinement fails on weight, counters, junctions or icon/type integration. This is an adapted working procedure, not a formula from a book. Keep the feature map and scope locks from [reference and proportion studies](reference-and-proportion.md) authoritative.

1. Freeze original, current draft, exact text, target sizes and retained signature features. Mark the actual locations of the reported weakness on a matched-scale comparison. If no artwork is available, record a hypothesis and hold visual conclusions.
2. Form one testable hypothesis per candidate: for example, a heavier inside contour is closing a counter or an icon/name gap breaks the lockup. Key each candidate to its faithful or authorized-alternative track and that track's feature map. Scope determines permitted parameter groups: kerning-only freezes icon paths, permits spacing changes only and skips contour work; unrelated geometry observations stay proposals. Before assuming the symbol needs more weight, compare both sides of the full-lockup imbalance: symbol contour, wordmark weight/proportion and their spacing. An outlined initial beside filled bold lettering is a hypothesis to test, not an automatic defect. If typography is locked, record that side as an observation/proposal and change only permitted groups. Keep an unchanged control and change one permitted parameter group at a time (stroke/contour, junction, spacing or lettering). Do not bundle unrelated fixes that prevent attributing the result.
3. Only when contour work is authorized, inspect both the outside silhouette and inside counterforms. Preserve path direction and compound-path holes; adjust relevant handles and tangent continuity rather than replacing a distinctive outlined form with a generic filled glyph. Record which points/curves changed. Measure relevant counters, channels and junction gaps on the original and candidate in stated units at a defined common scale where tools permit; otherwise mark measurements pending. Increasing weight is rejected when it closes a valued channel or worsens congestion, even if the outside silhouette looks stronger. Inspect the clean render as well as editable paths; a technically smooth curve may still look poorly balanced.
4. Compare control and candidates in a clean same-scale sheet at enlarged detail, intended minimum and smaller stress sizes, in one color and reversed use. Do not normalize away the weight or width difference being tested. Check retained connections, negative-space rhythm, unintended tangencies, clearance around valued figurative/decorative cues (such as botanical elements) and apparent mass. Original intentional overlaps that merge at stress size remain reproduction limits; propose a separately authorized size-specific variant rather than silently removing them. In spacing-only work, contour/mass checks are observations only. Return each promising icon to the same exact-name horizontal/stacked lockups where scoped; an isolated icon win may fail the complete composition. Inspect the symbol-to-first-letter junction and letter/word/line spacing across the full name for uneven rhythm.
5. Select only a change that addresses the stated defect without losing a feature retained in that track's feature map or creating a new use failure. Record observed benefit, regression and uncertainty, not merely a preference score. If all candidates crowd, merge or lose recognition, reject the set and revise the hypothesis rather than choosing the least bad result. Keep fabrication and audience evidence open where absent.

Reference cues become a concrete trial (such as a shared curvature rhythm or closer icon/type relationship), with an expected benefit and a test. Keep the source cue distinct from the original geometry produced; do not trace book marks or claim a reference's reputation transfers to the candidate. A ratio overlay, path validator or polished mockup cannot override a failed clean-artwork comparison.

## Sketch-to-native evidence

Generation-tool sketches are exploration evidence, whether pixels or automatically produced vector shapes. Compare the drawing hypotheses, then construct or clean the chosen direction as genuine editable native geometry with the approved text/font source. Inspect paths and actual painted outputs, save/reopen the master and compare exports. Anchor counts, path declarations and construction assertions do not demonstrate rendered quality or user acceptance. Preserve the preferred source and rejected sketches separately; do not substitute an attractive preview for native production proof.

## Native detail diagnostics

When offset, boolean or stroke-based contour work is in scope, inspect the edited joins at enlarged detail for tiny reversing spurs, slivers and unintended cuts that a full lockup can hide. Compare editable paths with actual painted bounds: a stroke centerline can clear a neighbor while its painted edge touches it. Where subtraction relies on stroke width, use a preserved test copy with actual expanded stroke geometry or an equivalent painted-bound operation with recorded method, units and measured tolerance against expanded geometry; inspect the resulting contour and clean export. Do not expand or flatten the preserved editable master merely to satisfy a check.

For figurative negative-space cuts, inspect endpoint meaning as well as clearance. A blunt endpoint or abrupt width change may read as an accidental scratch instead of a vein, fold or other intended cue. Treat termination/taper as an isolated contour-group trial, not bundled with stroke-weight changes. Test taper/termination only where the retained-feature map and authorized scope permit it; taper is a hypothesis, not a universal requirement. Compare against the unchanged control and do not replace a purposeful blunt terminal or close a valued channel.

Derive enlarged diagnostics and full-lockup exports from the same saved candidate geometry and source revision. Reuse the actual construction functions/objects when generating both, or crop/enlarge the exact candidate; when regenerating, verify full-export geometry and parameters against the saved candidate before using its detail. If parity cannot be established, crop the saved export and mark regeneration unverified. A separately redrawn detail is not proof of the full logo. Bind both evidence files to that revision and record expansion/export state in the existing [drawing-test evidence fields](../../../templates/logo-study.md). Use enlargement to locate defects, then reassess the existing junction, tangency and rhythm criteria at intended real size. An enlarged cleanup alone does not establish optical improvement or [user visual acceptance](../../design-logo-evaluation/references/review-contract.md#separate-acceptance-states-and-drawing-evidence).
