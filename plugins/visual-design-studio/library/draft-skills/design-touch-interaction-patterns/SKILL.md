# Touch interaction patterns

Version-Timestamp: 2026-09-11T20:08:06-04:00

## Inputs and scope

Read the [advanced workflow](../../DISPLAY-ADVANCED-SKILLS.md). Reuse accepted `touchscreen-design` inputs, source versions, objective and constraints. Dependencies express information needs, not mandatory repeated work. Scope is screen content and interaction, not fixture design. Unknown facts remain unknown.

## Method

Specify tap, scroll, swipe and selection behavior with visible alternatives to gestures. Identify scroll containers and prevent accidental activation while scrolling. Provide immediate feedback, duplicate-tap handling and clear selected/disabled states. Use actual device constraints.

## Deliverable and handoff

Interaction pattern specification and event/state examples. Include exact files actually created, candidate status, assumptions, failed checks and next owner through the [handoff](../design-stage-handoff/SKILL.md). Proposed paths are not produced files. No installed tool, publication authority or provider access is implied by this skill.

## Acceptance

Test imprecise input, rapid taps, scroll-versus-tap and non-gesture alternatives. Record observations separately from expected behavior. Missing runtime evidence remains pending; do not label plans or descriptions tested. Keep prior approved versions recoverable.
