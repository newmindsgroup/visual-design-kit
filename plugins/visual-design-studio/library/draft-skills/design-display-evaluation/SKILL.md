# Display evaluation

Version-Timestamp: 2026-09-11T09:45:01-04:00

Status: authored project-local instructions; not installed or production-certified.

## Inputs

Read the relevant [display workflow](../../DISPLAY-WORKFLOW.md) and reuse accepted inputs from the [display brief](../../templates/display-design-brief.md). Dependencies identify information needed, not mandatory repetition of approved work. Preserve baseline locks for precise changes.

## Method

Freeze brief-specific criteria before evaluating. Separate factual correctness, brand fit, visual hierarchy, typography, originality, motion craft and target performance. Compare original and revised work with the same content and conditions. Do not declare taste objectively proven by an automated score.

Review glance/mid-loop comprehension, distance/angle, glare, clutter, seams, longest content, silent playback, session reset and failure states as applicable. For applicable interactive web content evaluate flash limits, pause/stop/hide and interaction-animation requirements separately; reduced-motion preference alone does not certify accessibility. For uncontrolled public displays choose a safe motion treatment and obtain applicable installation review.

Define the intended outcome and measurement method. Proof-of-play establishes playback records, not attention, comprehension or sales causation. Use appropriately scoped observation or task testing; do not activate cameras/tracking or collect personal information by default. Record uncertain results and actionable revisions. Field checks need actual devices/site, not mockup confidence.

## Output and acceptance

Acceptance matrix with criterion, method, target, observed result, evidence, limitation and owner. Label specification, local-render, player and field acceptance separately; feed observed failures into existing reviewed learning workflow.

Carry actual files, source versions, assumptions and remaining checks through the existing [stage handoff](../design-stage-handoff/SKILL.md).

Apply flash/luminance/red-transition analysis to all rendered motion, including non-interactive loops, using the motion specification and actual exported file. Unverified safety remains a hold. Feed evidence into [reviewed skill improvement](../../SKILL-IMPROVEMENT.md). Confirm the applicable accessibility version and target-specific requirements rather than assume a reference link certifies compliance.
