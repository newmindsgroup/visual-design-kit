# Asset preparation

Version-Timestamp: 2026-09-11T19:51:13-04:00

## Objective and inputs

Produce asset preparation within the user's screen-content scope. Read the [screen workflow](../../SCREEN-CONTENT-SKILLS.md) and reuse approved upstream files, brief, source versions and constraints. The catalog dependency `display-discovery` identifies required information, not a mandatory rerun. Missing inputs are explicit assumptions or scoped holds.

## Method

Inventory supplied logos, footage, packshots and fonts with source, version, rights scope, expiry, resolution and editable status. Identify outdated packaging before editing. Preserve originals; make masks non-destructive and inspect fine edges on light and dark backgrounds. Never infer permission from public availability.

## Output

Asset manifest, prepared layers and unresolved asset requests. Carry source version, candidate status, editable file location, dependencies, limitations and next owner in the [handoff](../design-stage-handoff/SKILL.md). Choose an available tool suited to the artifact; a skill does not establish authentication, paid allowance or native editing capability.

## Acceptance

Check label spelling, alpha edges, source resolution and rights for each intended output. Record actual evidence and failures. Never label an unexecuted check passed. Maintain the approved baseline until the candidate is accepted.
