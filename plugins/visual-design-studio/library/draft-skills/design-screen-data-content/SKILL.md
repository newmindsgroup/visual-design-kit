# Data-driven screen content

Version-Timestamp: 2026-09-11T20:08:06-04:00

## Inputs and scope

Read the [advanced workflow](../../DISPLAY-ADVANCED-SKILLS.md). Reuse accepted `display-campaigns` inputs, source versions, objective and constraints. Dependencies express information needs, not mandatory repeated work. Scope is screen content and interaction, not fixture design. Unknown facts remain unknown.

## Method

Define field types, source ownership, freshness, units and update rules. Separate missing, zero and stale values. Specify layout limits and safe fallback rather than displaying guessed prices or empty placeholders. Preview extreme data and record refresh failures.

## Deliverable and handoff

Data contract, layout states and fallback matrix. Include exact files actually created, candidate status, assumptions, failed checks and next owner through the [handoff](../design-stage-handoff/SKILL.md). Proposed paths are not produced files. No installed tool, publication authority or provider access is implied by this skill.

## Acceptance

Exercise null, zero, unusually long values, stale feed and expired promotion. Record observations separately from expected behavior. Missing runtime evidence remains pending; do not label plans or descriptions tested. Keep prior approved versions recoverable.
