# Reference and campaign consistency

Version-Timestamp: 2026-09-12T11:33:18-04:00

## Inputs and workflow

Read the [media workflow](../../MEDIA-QUALITY-WORKFLOW.md) and reuse accepted upstream inputs. Use the [production packet](../../templates/media-quality-packet.md) for concrete inputs and outputs. Missing evidence stays explicit; tool availability is not production acceptance.

Create a reference manifest with stable ID, path/hash, rights, version, role and authority. Roles are product truth, character identity, style, composition and environment. Resolve conflicts explicitly: a style reference cannot override factual product geometry or an approved logo. Annotate each reference's intended influence and exclusions.

For characters, record silhouette, proportions, face details, costume, palette and allowed expressions/poses; provide multi-view references when available, and mark unseen details unknown. For campaigns, establish lighting, framing, color treatment, texture and motion invariants. Compare a contact sheet across shots and formats, not isolated frames. A repeated seed is not proof of identity consistency. Training a persistent character model is a separate data action. Return a versioned reference pack, invariant checklist and exceptions.

## Handoff and acceptance

Return artifact locations, exact baseline, candidate status, observed checks, remaining defects and next owner through the existing [handoff](../design-stage-handoff/SKILL.md). Apply the [rubric](../../templates/media-quality-rubric.md). Preserve original assets and follow the [media execution contract](../../MEDIA-GENERATION.md). Stop at the agreed revision/budget limit and report an unresolved result rather than silently changing the brief.
