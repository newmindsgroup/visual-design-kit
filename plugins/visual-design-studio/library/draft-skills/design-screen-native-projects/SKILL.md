# Reusable native production projects

Version-Timestamp: 2026-09-12T11:33:18-04:00

## Inputs

Read the [production workflow](../../SCREEN-PRODUCTION-WORKFLOW.md). Reuse accepted `display-production` inputs, source versions, target specification and user scope. Dependencies require information, not restarting approved work. No fixture design is included.

## Method

Choose the required editable format first. Organize sources, replaceable layers, text, timeline and exports. Use native app verification to check reopen, replace, render and reopen again. List fonts, linked assets, app version and missing plugins. Interchange SVG is a starter, not proof of native timeline compatibility.

## Outputs

Editable starter project, replacement instructions and native reopen/export evidence. Use the [stage handoff](../design-stage-handoff/SKILL.md). Hand off actual files, version, candidate/approved status, dependencies, failures and next owner. Proposed paths are not produced artifacts; no skill grants external activation, spending or credentials.

## Acceptance

Replace a product and longer headline without losing locked elements. Without an available target app or actual native project, mark native readiness pending. Record executed evidence separately from plans. Use the [example](../../examples/screen-production/README.md) only within its declared scope.
