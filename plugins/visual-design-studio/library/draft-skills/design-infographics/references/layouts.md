# Choose structure, then style

Version-Timestamp: 2026-09-08 19:56:22 AST

This is an original selection repertoire, not a universal list of styles or a ranking of trends. Select for the information, audience, brand and medium. Different arrangements of identical facts must preserve meaning.

| Structure | Useful for | Watch for |
| --- | --- | --- |
| Single key fact with supporting evidence | One fast takeaway, display or slide | A large number without denominator/context |
| Ranked bars or dot plot | Comparing categories | Truncated bars and unreadable labels |
| Comparison columns or matrix | Alternatives across consistent criteria | Unequal criteria or implied winners without evidence |
| Timeline | Events in sequence | Equal spacing pretending to show unequal elapsed time |
| Numbered process or swimlanes | Steps, decisions, responsibilities | Missing branches, exits and ownership |
| Journey strip | Experience over stages | Fictional emotion presented as observed research |
| Hierarchy or nested groups | Levels and membership | Decorative size suggesting unsupported magnitude |
| Cycle | Recurring process | Implied feedback or inevitability without basis |
| Annotated cutaway or exploded view | How parts work together | Attractive but physically inaccurate relationships |
| Map with callouts | Geographic distribution or location | Area bias, poor boundaries and missing normalization |
| Small multiples | Comparable trends or segments | Different scales hiding differences |
| Distribution or relationship plot | Variation or association | Correlation presented as causation |
| Part-to-whole bar, waffle or limited pie | Shares of a genuine whole | Nonexclusive categories, missing total or too many slices |
| Editorial sequence or modular grid | Several connected explanatory sections | Equal visual weight for unequal importance |
| Flow or Sankey | Measured movement between stages | Invented widths or quantities that do not reconcile |

Style options: restrained editorial, Swiss/grid-based, technical schematic, flat vector, pictogram-led, hand-drawn explanatory, isometric illustration, photographic collage, bold typographic, playful geometric, monochrome linework and dimensional/3D illustration. Choose one coherent vocabulary or a justified combination. Isometric/3D can explain objects but should not distort quantitative marks. Hand-drawn must still preserve exact values and legible labels. Photographs require rights and accurate subject context.

Record palette roles, type hierarchy, grid/spacing, stroke weight, icon perspective, illustration texture and annotation conventions. Build a small reusable legend and component set only for selected scope. Carry the same rules into responsive, print, slide, social and display variants while reordering or simplifying content as needed. If a variant omits detail, link to the full source rather than removing critical qualifications.

A successful style is readable and appropriate, not merely current. Trend research belongs in the reference-direction capability, with dated sources and a recorded reason for adoption.
