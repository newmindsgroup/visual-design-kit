# Still-image-to-motion adaptation

Version-Timestamp: 2026-09-11T20:08:06-04:00

## Inputs and scope

Read the [advanced workflow](../../DISPLAY-ADVANCED-SKILLS.md). Reuse accepted `screen-reconstruction` inputs, source versions, objective and constraints. Dependencies express information needs, not mandatory repeated work. Scope is screen content and interaction, not fixture design. Unknown facts remain unknown.

## Method

Identify campaign elements that can move without changing meaning. Preserve approved artwork and animate separate layers. Choose subtle depth or reveals when source resolution limits movement. Obtain approval for reconstructed/inferred content; preserve a static fallback.

## Deliverable and handoff

Layer plan, storyboard and editable motion candidate. Include exact files actually created, candidate status, assumptions, failed checks and next owner through the [handoff](../design-stage-handoff/SKILL.md). Proposed paths are not produced files. No installed tool, publication authority or provider access is implied by this skill.

## Acceptance

Compare held frames with approved still; inspect exposed gaps, edge artifacts and label deformation. Record observations separately from expected behavior. Missing runtime evidence remains pending; do not label plans or descriptions tested. Keep prior approved versions recoverable.
