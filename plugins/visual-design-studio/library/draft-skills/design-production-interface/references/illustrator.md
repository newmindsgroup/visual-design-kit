# Illustrator production workflow

Version-Timestamp: 2026-09-10 20:21:06 AST

Use for vector identity assets, icons, diagrams, illustration and multi-artboard production when the recipient needs editable vectors or an Illustrator master. Simple SVG work can remain in code if all declared needs are met; do not imply an AI master was produced from a preview.

Before action: load approved geometry/token/content references and actual app version. Verify a local scripting or UI route, or the exact connector operation. Adobe cloud AI rendering/data merge does not imply desktop object editing. Reuse vetted existing skills where suitable; do not create a new bridge by default.

Work on a candidate with named artboards/layers and identifiable objects. Preserve editable text in the source unless the brief explicitly requires outlines; an outlined delivery copy must not destroy the editable master. Resolve font rights, linked/embedded assets, dimensions, units and applicable color/profile/bleed rules before final export. Preserve vectors and document any raster effects.

Acceptance: save the actual native master if required; close/reopen the candidate and inspect artboards, object/text editability, geometry, colors and asset links. Inspect each requested SVG/PDF/raster export in its intended viewer for bounds, clipping, text, effects and profile requirements. Perform one controlled revision without changing preserved properties. Native save/reopen and visual checks are mandatory evidence for claiming this route verified.

## Control and recovery

Discover the actual control route and re-read native accessibility state before choosing controls; do not hardcode UI indices. Specify fonts, missing-font handling and dialog behavior before automation. Never suppress unresolved production requirements. Preserve progress and partially created work before recovery; do not force-quit unrelated documents.

Inspect SVG font embedding and outlines explicitly. Outlines may preserve appearance but do not retain editable or semantically readable text. Preserve the native text master and meet the consuming medium's accessibility requirements. A project may require live SVG text with a licensed font instead. Development fixture scripts are not arbitrary-document executors.

Use [shared production routing](../../../SOFTWARE-PRODUCTION.md) and [medium acceptance](../../../TOOLCHAINS.md); the existing work record and handoff remain authoritative.
