# Canva production workflow

Version-Timestamp: 2026-09-10 20:28:53 AST

Use for editable template-based campaigns, sales decks, social variants or collaborative marketing material when Canva meets the recipient's needs. Discover suitable vetted Canva editing, template, bulk or resize skills when available on the destination. Verify access and supported operations before reuse; absent integrations remain a routing gap.

Verify account/design/brand-template permissions and the exact format/operation entitlement. Premium elements, autofill or export paths can have separate limits; the installed app/connector alone proves none of them. Inspect the selected template/design and its editable content before changing it. Work in a candidate copy when preserving a baseline is required. Follow the connector's actual editing transaction lifecycle and verify saved state; a preview-only transaction is not a saved deliverable.

Apply approved text/assets/style and check each selected size independently. Do not assume imported PDFs/PPTX or flattened images preserve native object structure. Keep editable native design references and document font/media/layout conversion losses. Confirm a usable export route: do not assume the current connector exposes export; use an authorized first-party UI/API route only after its availability and entitlement are verified.

Acceptance: reopen the design/version in the editor, inspect meaningful editability, notes where relevant, overflow, content and brand consistency. Open each actual export in its target viewer, verifying pages, dimensions, fonts, media and selected format behavior. Record stable design ID and exported local bytes for the existing manifest. Do not share, publish or activate a campaign from an export request alone.

For native text changes, verify editing focus before typing and inspect for unintended objects. Check the final export against the baseline. Inspect actual profile and transparency rather than inferring them from a successful default download. Native editor, connector transactions and batch production each need their own evidence.

Use [shared production routing](../../../SOFTWARE-PRODUCTION.md) and [medium acceptance](../../../TOOLCHAINS.md); the existing work record and handoff remain authoritative.
