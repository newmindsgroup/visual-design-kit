# Print and physical production

Version-Timestamp: 2026-09-10 20:21:06 AST

Begin with the recipient's required stock/material, final trim, bleed, folds/finishing, color workflow, ink limits, PDF standard and proof process. Unknown printer requirements hold print-release readiness, not internal composition work. Do not prescribe one DPI, CMYK profile or bleed amount for every job.

Use an available application suited to the source: Illustrator for vector sheets/marks; a layout application for multi-page editorial work; Photoshop for raster preparation. Confirm its actual capabilities. Keep editable text/source, linked assets and fonts traceable. Review overprint and knockout, rich-black versus small text treatment, spot separations, transparency and effective image resolution only as applicable. A vector-only sheet can mark raster-resolution checks not applicable with evidence.

Produce a preflight record listing expected and observed page/trim/bleed boxes, color/output intent, embedded fonts, links, overset text and relevant print settings. PDF/X compliance is not inferred from extension or a selected preset. Inspect the exported PDF in an actual renderer and compare content to the master; reopen/edit native source for native editability claims. An RGB proof may be useful internally but does not become a press-ready file.

Keep print PDF and accessible digital document as distinct outputs if necessary. Outlined text protects appearance but loses text semantics; preserve the editable master. Tagged/reading-order acceptance needs actual inspection, not just a metadata flag. Record printer proof, material/color verification and approval separately. The laboratory's internal print candidate is a teaching artifact, not a certified production profile.
