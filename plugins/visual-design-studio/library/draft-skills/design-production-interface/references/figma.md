# Figma production workflow

Version-Timestamp: 2026-09-10 20:21:06 AST

Use when collaborative UI layouts, native components/variants, auto layout, variables/tokens, prototype links or a Figma design handoff are required. Read-only design extraction, native canvas authoring and exporting are different capabilities; verify each selected operation.

When the brief requires local Figma desktop, verify that app's actual version, launch and file-editing access; browser-only evidence does not satisfy it. Otherwise use the authorized route that meets the deliverable. MCP is optional and must be discovered, not inferred from an installed skill. Record actual file/team permissions and supported operations. Follow the Figma-versus-Adobe table in SOFTWARE-PRODUCTION.md; preserve separate artwork, photo and UI masters. No authoring-host fixture status transfers.

Inspect canonical brand/token rules and existing Figma structure before importing or generating. Use native text, frames, components and variables when editability is required; do not wrap a screenshot in a frame and call it an editable UI system. Choose source-of-truth and mapping direction; document unsupported token/layout/type effects and avoid a second conflicting system. Preserve existing instance relationships and approved states during revisions.

Acceptance: reopen the actual file/version and inspect native nodes, relevant variants, auto layout, variable bindings and prototype edges. Verify selected export behavior and the target code/browser separately if implementation is part of scope. Record file/node IDs and approved access, with local export evidence where needed; no permission change or sharing is implied.

This workflow remains operation-specific. Reuse recorded evidence only for its tested scope; verify the required native editing, export and reopen behavior for each new deliverable.

Use [shared production routing](../../../SOFTWARE-PRODUCTION.md) and [medium acceptance](../../../TOOLCHAINS.md); the existing work record and handoff remain authoritative.
