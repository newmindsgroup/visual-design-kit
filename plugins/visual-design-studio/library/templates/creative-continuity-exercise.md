For each case record actual inputs read, first output, observed defect, correction, final output, evidence, passed/failed/pending criteria and next action. Record explicitly if no case ran. Never replace a failed first output with the corrected result in the evidence log.

Verify the review process identifies the actual defect. Do not claim detection because the instructions mention it. A visually appealing fault must still be rejected where it violates a requirement.
