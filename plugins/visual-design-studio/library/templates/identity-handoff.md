# Identity handoff record

Version-Timestamp: 2026-09-11T19:25:03-04:00

Parent: [identity workflow](../IDENTITY-WORKFLOW.md). Markdown companion to existing work/manifest records, not a new JSON schema. Fill only relevant fields; unknown is not approval.

- Scope: new/refresh/revision/evaluation/delivery; requested outputs and owner.
- Evidence: strategy/direction IDs, source dates, approved versus inferred rules and unresolved conflicts.
- Name: exact text, language/diacritics/case, architecture, approval-for-design and separate screening/clearance status.
- Baseline: canonical master path/version/hash, approved locks, permitted delta and preservation evidence.
- Concepts: stable IDs, rationale, comparative criteria, selected/provisional/rejected disposition.
- Refinement: editable tool/version, geometry/lettering changes, live text/outline intent and comparison.
- Variants: ID, parent master, purpose, lockup text, backgrounds, size rules, approval, actual files.
- Tests: variant/file version, use/size, method, expected criterion, result, evidence and unresolved owner.
- System: canonical typography/color/layout/visual/motion/verbal record links and exceptions.
- Rights: source asset/font, license evidence, redistribution/embedding limits, owner and unresolved use.
- Guidelines: source version, approved/provisional sections, requested rendered editions and checks.
- Delivery: existing manifest ID, source/export binding, format/profile/dimensions, licenses and recipient instructions.
- Migration: old/new mapping, coexistence, authorized rollout, deprecated files and rollback.
- Decision: creative approval distinct from legal, native/rendered, supplier/device and audience acceptance.
