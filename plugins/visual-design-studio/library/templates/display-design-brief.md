# Display design brief

Version-Timestamp: 2026-09-11T09:45:01-04:00

Parent: [display workflow](../DISPLAY-WORKFLOW.md). Complete relevant fields with evidence or explicit unknown/not-applicable status. This is a Markdown companion, not a newly validated JSON schema.

- Identity: project/version, owner, baseline files and permitted changes.
- Goal: audience task, message, intended action, success criterion and measurement.
- Brand: existing approved / inferred provisional / new; guidelines, claims, asset rights and locks.
- Environment: venue, distance/angle, dwell time, lighting/glare, competing signage and measured/assumed evidence.
- Screen: physical dimensions, canvas, orientation, pixel mapping/pitch, safe areas, seams and installation drawing.
- Behavior: passive / dynamic non-touch / interactive; session, input and assistive requirements.
- Content: approved text/claims/prices/dates, hierarchy, languages, maximum lengths and product fidelity.
- Direction: references, original visual rules, contextual mockup, selection status and rationale.
- Motion: purpose, storyboard, style frames, scene IDs/timing, animatic, loop/entry-midway, silence/audio and fallback.
- Data: source, owner, freshness threshold, update/expiry, cache and failure behavior.
- Campaign: location, timezone/daypart, start/end, variants, priority and withdrawal.
- Touch: state map, reach/input, help, timeout warning/extension/reset, privacy and uncertain-operation handling.
- Production: tool/version, editable source, assets/fonts, player constraints, exports and manifest.
- Acceptance: criterion, method, actual result/evidence, unresolved prerequisite and owner; local versus field status.

- Conflicts: partial guidelines, conflicting sources, per-rule confidence, authority and owner resolution.
- Rights detail: font/stock/talent/music scopes, territories, embedding permissions, end dates and fallback.
- Clock and expiry: source/timezone, daylight-saving behavior, unknown clock and offline expiration enforcement.
- Wall recovery: bezel compensation, sync tolerance, panel failure and desync fallback.
- Physical access: applicable requirements, deployment owner, specialist checks, peripherals and evidence.
- Motion safety: flash/luminance/red-transition test method, criteria, exported file identity and measured results.
